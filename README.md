# Dangle ⚡

A high-performance, minimalist web puzzle game with pure rubber physics.

Play online: **[https://deven-ps.github.io/Dangle/](https://deven-ps.github.io/Dangle/)**

---

## About The Game

**Dangle** presents a tangled cluster of rubbery threads, resembling loose hair or bush vines.
- When you click and drag any node, connected neighbors stretch, bounce, and oscillate elastically with Barnes-Hut spring dynamics.
- Active short circuits (wire crossings) spark in neon red.
- Your objective is to untangle all crossing wires. Once all intersections are cleared, the grid powers on with luminous emerald green.

## Features
- **10 Progressive Stages**: From 6 nodes to 200 nodes.
- **Pure Rubber Physics**: Dynamic Bezier splines and harmonic spring tension.
- **Ambient Breathing**: Continuous gentle organic motion while idle.
- **Zero Lag / Zero Dependencies**: Built with pure client-side HTML5, CSS3, and JavaScript. Audio synthesized via Web Audio API.
- **Ultra-Minimal UI**: Subtle `mm:ss` timer, stage tag, and a spark light hint button.

## Local Play
Open `index.html` in any modern web browser or run:
```bash
python -m http.server 8080
```
